## What #27441 adds

For `8 < ne11 <= 32` (spec-decode verify/draft regime):

| piece | role |
|-------|------|
| `kernel_mul_mm_s` / `s2` | skinny tiles 32x16 (or 16x16) instead of stock 64x32 |
| `kernel_mul_mm_sk` + `sk_reduce` | 4-slice split-K; partials in dst scratch; **fixed-order** reduce |
| env knobs | `GGML_METAL_MM_SKINNY_MAX` (default 32; `0` = stock), `GGML_METAL_MM_SPLITK`, `GGML_METAL_MM_MIN`, `GGML_METAL_MV_EXT_*` |

Default break-even stays **8** (unlike our B5 pin of 32). Includes `iq4_xs` host_names (matches fixture weights). **No TQ3_1S / TQ4_1S** instantiations.

PR claim: bit-reproducible run-to-run; **not** bit-identical to stock/`mul_mv` (summation order can flip greedy ties).
